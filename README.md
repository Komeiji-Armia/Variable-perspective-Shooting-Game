# Variable-perspective-Shooting-Game
このプロジェクトは授業で作成した成果物を一部個人情報をぼかしてリポジトリに入れています<br>

<h4>概要</h4>
自機を操作して攻撃を放ち、敵を倒してスコアを稼ぎ、クリアになる点数を目指すシンプルなゲームです。<br>
無論敵も黙っていないので攻撃をしてきます。何度も当たって残機が0になるとゲームオーバーになります。<br>
躱しましょう。当たらなければどうということはありません。<br>

プレイ中のキー入力により、 **任意のタイミングで俯瞰視点と主観視点を変更できます。** 本作の独自性と言える部分です。<br>
